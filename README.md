## Decodifica CW

Il decodificatore Morse usa il motore **SmartCW**: rilevamento tono Goertzel
con AFC, gate adattivo con isteresi e decodifica bayesiana a beam search con
modello linguistico radioamatoriale. Architettura e risultati dei test:
[SmartCW/README_SMARTCW.md](SmartCW/README_SMARTCW.md).
